# Debugger for the Conversion Tool
Current Version 0444

# Compatable with Tool Versions:
- 0.4.4rc3
- 0.4.4rc4

# Usage
- Drop the debugger.pck file into the same directory as the program. Once you run the program, it will generate a debug folder and create debug logs that detail varous actions taken within the tool and will allow me to better provide support and diagnose issues
- you can also create the debug folder by hand and place the .pck there, but thats not required or necessary unless you prefer a clean directory
- If you're done with the debugger, you can either rename it, delete it, or otherwise remove it from that directory and the tool will stop generating log files
